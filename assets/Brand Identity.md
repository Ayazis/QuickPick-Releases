# QuickPick Identity

## Core Definition

QuickPick is a Windows action launcher that executes predefined actions instantly from the cursor.

It is not a search tool.  
It does not guess.  
It does not automate workflows.  

It performs exactly what the user defines.

---

## Brand Positioning

QuickPick is positioned as a precision utility for power users.

It prioritizes:

- Speed
- Determinism
- Spatial interaction
- Local control

It avoids:

- Discovery-based interaction
- Recommendation systems
- Automation abstractions
- Marketing-driven features

---

## Interaction Identity

QuickPick’s identity is behavioral, not decorative.

Summon → Select → Execute

The interface appears at the cursor.  
Actions are spatially arranged.  
Selection is immediate.  
Execution is explicit.

No intermediate steps.

---

## Visual Language

### Shapes
- Hexagon = Action  
- Circle = Application  

Shape carries semantic meaning and must remain consistent.

### Color
- Neutral-first interface
- Teal (#0F7D80) indicates intent or execution
- No decorative color usage

### Layout
- Centered interaction cluster
- No scrolling within summon UI
- Designed for repeated spatial use

---

## Tone

All QuickPick communication must be:

- Direct
- Precise
- Minimal
- Technical

Avoid emotional language.  
Avoid productivity claims.  
Avoid feature exaggeration.

---

## Brand Principles

1. If it slows execution, remove it.
2. If it hides behavior, clarify it.
3. If it adds visual noise, simplify it.
4. If it introduces ambiguity, reject it.

QuickPick’s identity is defined by restraint and determinism.
