Community & Support

Resources for troubleshooting, updates, and best practices.

Start Here

If you are new to QuickPick, begin with the About page, then install the latest build from Download.

Issue Reporting

When reporting a problem, include:

  • Windows version and build
  • QuickPick version
  • Exact steps to reproduce
  • Expected behavior vs. actual behavior

Before You Ask for Help

  • Check Changelog for known fixes and behavior changes
  • Confirm your action bindings and trigger configuration
  • Retest with a minimal action set to isolate the issue

Operational Guidance

QuickPick works best with stable, task-specific action groups. Keep groups focused and avoid overlapping hotkeys to preserve speed and predictability.

Community Guidelines

  • Be clear and respectful when asking for help
  • Share reproducible steps, not assumptions
  • Keep feedback technical and specific
  • Focus discussions on actionable improvements

Need Technical Support?

Use the latest release notes and troubleshooting guidance before submitting an issue.
