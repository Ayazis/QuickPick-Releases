## Creative

18 seconds, 1080 × 1920, 60 fps. Burned-in contextual copy; no voiceover. Main version includes a quiet, original synthesized audio bed that lowers during the volume adjustment, plus soft UI accents. A silent version is supplied separately.

Story: interruption (0–2s), product/context (2–4.3s), shortcut (4.3–6.1s), volume adjustment (6.1–8.3s), result (8.3–11.5s), resume work (11.5–14.7s), closing CTA (14.7–18s).

The interface is an illustrated demonstration using the same menu components as the website. The volume readout is a visual explanation of the action. Ctrl+Space is an example customizable shortcut.

Review the hook, how clearly the menu action reads on a phone, the pace, and the closing CTA. Confirm placement-specific overlays in the target platform's preview before publishing.
