Privacy

QuickPick is a local utility. It does not require cloud services to execute configured actions.

Data Handling

QuickPick is designed for local execution and local configuration.

  • Local configuration
  • No background telemetry
  • No mandatory cloud dependency

Operational Scope

QuickPick only performs actions you explicitly configure. It does not infer intent, upload usage data by default, or require a cloud account to run.
